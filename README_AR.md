# SPSS SBA PWA — ملفات النشر

## ما الذي يتضمنه المشروع؟
- `index.html`: واجهة تطبيق SPSS SBA الحالية.
- `manifest.json`: اسم التطبيق وأيقوناته وإعدادات التثبيت.
- `service-worker.js`: تخزين ملفات التطبيق الأساسية للتشغيل دون اتصال بعد أول زيارة.
- `icons/`: أيقونات التطبيق المشتقة من الشعار الرسمي المرفق.

## نشر مجاني من الهاتف عبر GitHub Pages
1. افتح https://github.com في متصفح الهاتف وأنشئ حسابًا أو سجّل الدخول.
2. أنشئ مستودعًا جديدًا (New repository)، وسمّه مثلًا `spss-sba-pwa` واجعله Public إذا كنت تستخدم GitHub Pages المجاني.
3. داخل المستودع اختر Add file ثم Upload files.
4. ارفع **محتويات هذا المجلد** كلها، لا ترفع ملف ZIP وحده. يجب أن يظهر `index.html` و`manifest.json` و`service-worker.js` في جذر المستودع، ومجلد `icons`.
5. اضغط Commit changes.
6. افتح Settings ثم Pages.
7. في Build and deployment اختر Deploy from a branch، ثم الفرع `main` والمجلد `/(root)`، ثم Save.
8. انتظر انتهاء النشر، وافتح الرابط الذي يظهر في صفحة Pages (عادةً `https://اسمك.github.io/spss-sba-pwa/`).
9. على Android افتح الرابط في Chrome، ثم قائمة ⋮ واختر Install app أو Add to Home screen.

## حفظ البيانات والخصوصية
- بيانات التطبيق تُحفظ محليًا في المتصفح/التطبيق عبر آلية التخزين الموجودة في الواجهة، ولا تتزامن تلقائيًا بين الأجهزة.
- تثبيت PWA لا يحوّل التخزين المحلي إلى قاعدة بيانات سحابية.
- خذ نسخة احتياطية من بياناتك بانتظام باستخدام ميزة التصدير داخل التطبيق إن كانت متاحة.
- تجنّب استخدام بيانات العملاء الحقيقية قبل اختبار التصدير والاستعادة.
- GitHub Pages ينشر الملفات علنًا؛ لا تضع أي ملفات بيانات عملاء أو نسخ احتياطية داخل المستودع.

## ملاحظات فنية
- يلزم HTTPS للتثبيت الموثوق؛ GitHub Pages يوفّر HTTPS.
- التشغيل دون اتصال يكون بعد فتح التطبيق مرة واحدة على الأقل، وقد تحتاج إلى فتحه عبر الإنترنت أول مرة لتخزين ملفات التطبيق.
- إذا حدّثت ملفات التطبيق لاحقًا، قد يحتاج المتصفح إلى إعادة فتح التطبيق/تحديثه حتى يستقبل النسخة الجديدة.
- هذه نسخة PWA محلية على الجهاز، وليست نظامًا متعدد المستخدمين أو مزامنة سحابية.
